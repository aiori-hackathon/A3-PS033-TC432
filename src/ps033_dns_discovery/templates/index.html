3. How the security pipeline works

01 — DNS discovery

Retrieve diagnostic service metadata from DNS TXT records.

02 — DNSSEC verification

Verify the TXT record's RRSIG using the locally pinned DNSKEY.

03 — Metadata validation

Validate required fields, authentication method and approved local endpoints.

04 — Authentication

Send a bearer token to the selected diagnostic service.

05 — Service invocation

Invoke the discovered endpoint and display its response.

4. Technical limitations

This is an educational local prototype. It uses a locally pinned DNSKEY and verifies the DNS TXT RRset signature. It does not implement full public DNS root-to-zone DNSSEC chain validation. Diagnostic measurements and traceroute responses are simulated. The mock services run locally for demonstration purposes.
