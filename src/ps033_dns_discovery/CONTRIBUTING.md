# Contributing

1. Create a branch for your change.
2. Use a Python virtual environment and install `requirements.txt`.
3. Run `python setup_lab.py` and `python -m pytest -v`.
4. Keep the lab loopback-only and do not add real credentials or private keys.
5. Update the README when behavior, setup, or limitations change.

Please include a concise description of the change and test results in your pull request.
